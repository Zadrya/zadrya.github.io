# zadrya.github.io

The website of [Zadrya](https://github.com/Zadrya/Application), a harm reduction journal for iOS and Android: landing page, privacy policy and support, in English and Spanish.

**Status:** placeholder. The site is built later in the project.

The site has no analytics, no third-party scripts and no cookies.

## Development

```sh
make setup   # install the git hooks, once per clone
make check   # before every commit
make ci      # before opening a pull request
```
